# Проект job_search
- это проект, который получает информацию о вакансиях с платформы hh.ru в России, сохраняет ее в файл и позволяет удобно работать с ней: добавлять, фильтровать, удалять вакансии

## Описание:

Проект включает в себя классы:
- Vacancy (хранит информацию о вакансии) включает в себя методы:
1. init - Инициализация
2. eq, lt, gt - Сравнение вакансий между собой (по зарплате)
3. cast_to_object_list - принимает список словарей (ответ от API hh.ru) выбирает из них нужные свойства, выдает список элементов класса Vacancy
4. cast_to_obj_from_file - принимает список словарей (с уже отсортированными данными) и выдает список элементов Vacancy
5. __salary_validation - принимает словарь - ответ hh.ru по зарплате, проверяет в какой валюте указана зарплата в ответе от hh.ru, берет курс валюты из файла data/exchange_rates.json и возвращает в рублях
6. to_dict - возвращает словарь с информацией о вакансии

- JSONSaver - класс для взаимодействия с json файлами, наследуется от абстрактного класса BaseSaver, включает одно приватное свойство с путем к файлу; методы:
1. init - инициализация
2. get_data - возвращает список словарей с вакансиями из json файла
3. add_data - принимает список вакансий list[Vacancy], проверяет вакансии на повтор и сохраняет уникальные в файл json
4. delete_data - принимает одну вакансию, если она сохранена в файле, удаляет ее оттуда 
5. __is_dict_in_list - проверяет наличие словаря в списке словарей, возвращает bool

- HeadHunterAPI (наследуется от абстрактного BaseApi) класс для работы с API HeadHunter с методами:
1. init - инициализация
2. __connect_api - приватный метод, делает апи запрос hh.ru и сохраняет ответ в свойстве __vacancies
3. get_vacancies - вызывает метод __connect_api и возвращает список словарей с данными о вакансиях

- ExchangeAPI Класс для получения курсов валют; методы:
1. init - инициализация 
2. exchange_rate - делает апи запрос и сохраняет ответ в json файл
